## About the site

A plain static site (HTML, CSS and a little JavaScript, no framework or build step), hosted on
GitHub Pages. It has a light and a dark theme, sets no cookies and uses no analytics.

```
index.html                              portfolio home page
projects/btc-mining-real-options.html   project write-up
assets/css/style.css                    styling and theme tokens
assets/js/main.js                       theme toggle, project filter
assets/img/                             project figures
assets/files/renato-quiliche-cv.pdf     CV
```

Equations on project pages are rendered with [KaTeX](https://katex.org); fonts are Inter and
JetBrains Mono from Google Fonts.
